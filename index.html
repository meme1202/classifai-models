How Models Work

📷

1. Image Input

The system receives a high-resolution image of the plant leaf. The image is validated for supported formats (JPG, PNG) and size constraints.

⚙️

2. Preprocessing

The image is resized to match the model's expected input dimensions (e.g., 224x224 px), normalized, and converted into a multi-dimensional tensor.

🧠

3. Feature Extraction

Deep neural network layers apply convolutional filters to identify edges, textures, and specific disease patterns within the leaf structure.

📊

4. Prediction Output

The final dense layer calculates probabilities. The system generates a confidence score and a visual Grad-CAM heatmap highlighting critical areas.
