# ClassifAI — Plant Treatment Classifier

AI dashboard for classifying plant leaf images as Treated or Untreated using multiple deep learning models.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript (static)
- **Backend**: Python Flask + TensorFlow/Keras
- **Models**: Advanced Custom CNN, MobileNetV2, EfficientNetB0, DenseNet121, ResNet50V2

## Running Locally
```bash
pip install -r requirements.txt
python app.py
```
Then open `index.html` in a browser.
